1.3.7
Bug Fixes
- Added Torpedo Launcher to the weapon priority list.
- Fixed: closing the update popup no longer snoozes the update for 14 days.
- Fixed: pasting a single object into the JSON box now correctly appends it (at the cursor position, automatically handling a stray trailing comma from copying it out of a list) instead of replacing the whole JSON, while - still keeping BaseType, OriginalBaseVersion, and UserData protection intact - so pasting a Planet Base's code into a selected Corvette no longer turns it into a Planet Base.
New Feature
- Added a bug notice banner that shows a short message when needed.
