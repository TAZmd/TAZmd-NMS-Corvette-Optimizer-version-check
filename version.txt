1.4.3
Bug Fixes
- SSM: The Confirm Save Changes screen now lines up UserData and Slot numbers correctly by their actual value instead of by list position, so mismatches are no longer shown on the wrong row.
- What's New popup no longer cuts off the last few lines of long changelogs.
- Object list colors (priority, tier warnings, duplicates) no longer show on Freighters and Bases, since those colors only apply to Corvettes.

New Features
- SSM: New "Add New Starship" button in Ship Slot Manager lets you assign a unique starships.
- Load File is now available for Freighters and Bases, not just Corvettes.

1.4.2
Bug Fixes
- The "Corvettes" and "Expedition Corvettes" headers disappearing after deleting the last corvette while the Add Corvette button stayed visible.
- The update and What's New windows could extend past your screen instead of scrolling.
- Paste All on the Objects list added objects instead of replacing them.
- Deleting a corvette still created a backup of the linked autosave file.
- Loading a save through Single File mode could create or point to the wrong backup folder.

New Features
- Added: Link indicators between the Persistent Player Base and Ship Ownership panels in Ship Slot Manager, showing which corvettes are correctly linked to their slot.
- Added: A "Known Bugs & To-Do's" section to the Report Bug window.

1.4.1
Bug Fixes
- Error messages now tell you exactly what went wrong, instead of just saying something is wrong.
- Pasting multiple objects at once no longer wipes out the rest of your list. Your existing work stays safe.
- The update popup no longer hides part of the message behind its buttons.
New Feature
- The app is now available in Spanish, German, French, and Simplified Chinese, next to English. Pick your language on first launch, or change it anytime in Settings.
- The title bar now matches the app's look, and dims when the window is not active.
- You can add a subtle color fade to the background, choose its direction, or turn it off in Settings.
- Buttons now resize automatically so text always fits, in every language.

v1.4.0
Bug Fixes
- Auto-save backups were accumulating unnecessarily and taking up disk space. These are now completely disabled.
New Feature
- When you update to this version and have a lot of old backups stored up, the app will ask you once what to do with them so nothing gets deleted without your permission.
- The app now has a menu bar at the top with easy access to Ship Slot Manager, Backups, Settings, and other options like Donate, Info, and Help.
- Settings is now a full page where you can control everything about how the app works, including what your backup folders are and how many backups to keep.
- You can now choose your own backup location instead of using the default folder. If you use multiple Steam accounts, each one gets its own folder automatically so backups don't get mixed up.
- Backups are now smarter about keeping old files. Instead of deleting by date, the app keeps only the number of backups you want and automatically removes older ones.
- Font sizes throughout the app can be customized to make everything bigger or smaller depending on what's comfortable for you.
