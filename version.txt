2.0.6
New Features
- The Corvette Library now displays the upload rules and Privacy Policy. You must accept them before using the library.
- The rules link on the upload page now opens the rules and Privacy Policy directly in the app.
- Download limits have been adjusted. You can now download a full set of 12 Corvettes without waiting.

2.0.5
Bug Fixes
- Galactic Trade, Teleport, Dressing, and Cooking rooms now correctly count toward their respective utilities in the Utility Score.
New Features
- Ship owners can now react to comments on their Corvette with a heart, thumbs up, or neutral face. These reactions are visible to everyone.
- The Utility Score now includes a Plant Tray. Planters, wall planters, and plant rooms contribute based on their plant capacity. The Nip Plant is no longer counted as a separate utility.

Side Note
- I tried to find a solution for ships where an object obstructs the cockpit, causing white flashes on the screen when you're being shot at in first-person view.
  Unfortunately, because there are so many different ship builds, it's impossible to create a solution that works for every setup.
  The best approach is to identify which object is obstructing the cockpit and manually move it to the top of the object order.

2.0.4
Bug Fixes
- The Utility score no longer overlaps the Your Corvettes list.
- Ship names on the Library cards now stay centered and no longer shift when icons appear.

New Features
- The comment box now shows the comment limits before you start typing.
- The Post button now waits by itself with a countdown when you reach the limit, instead of showing an error.
- The ship details panel no longer repeats the Import and Download buttons, the object count and the Utility list.
- When a download or import fails, the message now shows the reason.

2.0.3
New Features
- The Utility Score window now lists the utilities your Corvette is missing.
- The Corvette Library tab now shows the Utility Score of the Corvette you select on the left.
- You can now leave comments on a Corvette. Log in with Discord and download or import the Corvette first.
- Click a Corvette card to open a panel on the right with all details, instructions and comments.
- A bell shows how many new comments your Corvettes got. Click it to go straight to them.
- Every card now shows how many comments the Corvette has.
- The thank you window now lets you copy the builder name for Discord and leave a comment right away.
- You can now add a TikTok link instead of a YouTube link.
- The Corvette Library header now shows a clear path and a Back button.
- If a Corvette is rejected, you can now see the reason in My Uploads.

2.0.2
New Features
- Uploading Corvettes now requires a Discord login. You also need to be a member of our Discord server. The "Verify I'm human" check is gone, because the Discord login replaces it.
- Bulk upload now uses the Bulk role in our Discord server instead of an access code.
- The upload rules are now a link to the rules in our Discord, so the rules are always up to date. The old rules box is gone.
- After a successful upload you now see a thank you page, with tips on how to edit or remove your Corvette later.
- New "Builder login" button at the top of the library. After logging in you also get a "My Uploads" button with all your own Corvettes.
- In My Uploads you can edit/delete your Corvette: change the name, instructions and YouTube or Patreon links, upload a new JSON file with a reason for the update, and change, remove, reorder or add photos (drag a photo to the left to make it the primary photo). Your change is checked before it goes online.
- Updated Corvettes show an update icon next to the info icon, with "Updated v1" (or v2, v3, and so on) and the reason the builder gave. Corvettes with a new JSON file also move up in "Last submitted/updated".
- New sort option "Hidden gems": Corvettes with lots of utilities that have not been downloaded much yet.
- The thank you window now shows the Discord name of the uploader, so you know who to thank in the Thanks channel.
- New small siren button on every Corvette card to report a problem or a stolen ship.

2.0
NEW Corvette Library

The new Corvette Library lets you discover and use Corvettes made by other builders.
- Browse and search the community library.
- Sort by newest, most downloaded, Utility Score or builder.
- Filter by favorites and any utility. Click a utility to require it, or click it again to exclude it.
- View photos, utilities and a Utility Score for each Corvette.
- Import a Corvette directly into your save or download it as a file.
- Add your own Corvettes to the library, including photos, instructions, YouTube and Patreon links.

Other Improvements
- Added a other option for donations than PayPal as requested. If you like what I do, a tip is much appreciated.
- Added new Optimizer, Ship Slot Manager and Corvette Library tabs.
- Added Ship Details to edit ship class and base stats.
- Added Edit Priority List next to the Optimize Corvette button for direct access to the priority list.
- Added object group filtering.
- Add Corvette now fills empty ship slots instead of incorrectly reporting that the 12-ship limit has been reached.
- Added Discord access from the menu and About section.
- The file name bar, bottom messages and loading screen now follow the selected theme color.
- Improved the update window.

Bug Fixes
- Fixed Blender copying filling Position and Forward with zeros.
- Fixed incorrect object and ship names in several parts of the app.
- Fixed Expedition Corvette object names.
- Fixed haulers being incorrectly identified as Iron Vultures.
- Fixed adding multiple Corvettes using the same slot and name.
- Fixed several translation issues.
- Fixed scrollbar issues.
